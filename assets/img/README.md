# Recommended images and icons

The site works with no photographs, using inline SVG art and an icon sprite built into index.html.
Add these files to make it even stronger. All paths are relative to the site root.

| File | Size | Purpose |
|---|---|---|
| `assets/img/profile.jpg` | 600 x 600 px, JPG, under 120 KB | Portrait. Shown in the hero card automatically and replaces the RQ monogram. Use a plain, well-lit professional photo. |
| `assets/img/og-image.png` | 1200 x 630 px | Preview card for LinkedIn, WhatsApp and Google. A generated version is included. |
| `assets/img/favicon.svg` | any | Browser tab icon. Included. |
| `assets/img/projects/*.webp` | 1600 px wide, WebP, under 200 KB each | Optional real project visuals (Civil 3D design view, Navisworks federated model, as-built photo). See the confidentiality note below. |

## Before you publish any project image
- Blur colleague names, email addresses, file codes and anything marked confidential.
- Check with your employer that you may show NEOM, Diriyah Gate or SILZ visuals publicly.
- Prefer your own work (alignments, assemblies, Dynamo graphs, clash report layouts) over client drawings.

## Free icon and image sources if you need more
- Icons: Lucide (lucide.dev), Feather (feathericons.com), Heroicons (heroicons.com). The ones used here are Feather-style.
- Photos: Unsplash and Pexels for generic road and infrastructure images. Always credit if the licence asks.
- Compress images with Squoosh (squoosh.app) before uploading.
